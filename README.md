# 沖縄語辞典 Webアプリ

沖縄語の語句・意味を調べる辞書検索Webアプリです。

公開サイト: **[okinawago.app](https://okinawago.app)**

沖日辞典・日沖辞典・うちなーぐち活用辞典の3種類を選択し、前方一致・部分一致・後方一致で検索できます。検索結果の強調表示と各語の詳細表示に対応しています。

国立国語研究所の[沖縄語辞典 データ集](https://mmsrv.ninjal.ac.jp/okinawago/)などを検索・表示用に変換した[hissanova/okinawago_dictionary](https://github.com/hissanova/okinawago_dictionary)のデータを使用しています。出典・ライセンスの詳細は公開サイトの[このサイトについて](https://okinawago.app/about)をご覧ください。
